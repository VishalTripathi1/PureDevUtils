## Bulk UUIDs
Need 100 random UUID v4 values for a test fixture? PureDevUtils generates a batch locally in your browser, with copy-all and TXT/CSV export. The guide explains the 1,000-value limit and how to generate UUIDs in JavaScript, Java and Python.

## Nested JSON to Java
Nested API responses need more than a flat Java class. This walkthrough uses an order, customer and item list to generate POJOs or records, preserve hyphenated keys with Jackson, and review missing fields and numeric precision. Generation runs in your browser.
https://puredevutils.com/tutorials/nested-json-to-java-spring-boot

## URL encoding
Why does a space sometimes become %20 and sometimes +? This guide compares encodeURI, encodeURIComponent and form encoding with runnable examples, plus the %20 → %2520 double-encoding trap.
https://puredevutils.com/tutorials/url-encoding-explained
